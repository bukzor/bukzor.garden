# Correctness

The engine must implement Super Tic-Tac-Toe rules faithfully.

- Legal move generation matches game rules
- Win/draw detection is accurate
- Constraint propagation (next-board rule) is correct
- No edge cases produce invalid states

This is the primary goal. Without correctness, comparison is meaningless.
